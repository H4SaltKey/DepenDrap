# BGM tracks

Place the following loopable MP3 files in this directory. The application references these exact paths:

- `title.mp3` — title screen
- `match.mp3` — play mode selection and match setup
- `game.mp3` — active game and draw result
- `result_win.mp3` — victory result
- `result_lose.mp3` — defeat result
- `deck.mp3` — deck selection and deck building

Tracks loop automatically. The in-game and title BGM volume slider controls playback volume. Audio playback starts on page load when allowed by the browser; if autoplay is blocked, the first pointer or keyboard interaction starts it.
